## 三、详细操作流程（按顺序执行，做完一步验证一步）

> 
> 你机器上 MySQL **已经在运行**，所以我把原文档的"阶段A启动MySQL"省略了，直接从连接开始。

### 【本步目标】

在 Navicat 里连上 MySQL → 执行 `appstore_init.sql` → 创建 `appstore` 库 + 11张表 + 全部种子数据 → 验证数据正确。

### 【阶段 1】确认 root 密码（关键一步，卡住了先做这个）

因为你的 MySQL root 密码不是默认的 `root`，先把它找出来：

1. 打开 **phpStudy**（双击桌面图标，或打开 `D:\phpstudy_pro\phpStudy.exe`）
2. 在面板 MySQL 一栏右侧点 **"设置"**（或"修改密码"/"管理"）
3. 面板会显示当前 root 密码，或用"修改密码"功能**重置成一个你记得住的新密码**（比如 `123456`）
4. 把确认好的密码记下来，下一步要用

**【成功验证】** 面板能显示/修改密码且 MySQL 保持运行状态（绿色）。

**【新手避坑】** 改密码后 MySQL 可能要求**重启 MySQL 服务**（面板上先"停止"再"启动"），否则新密码不生效。如果密码怎么都试不对，就干脆用 phpStudy 重置一个全新密码。

### 【阶段 2】Navicat 连接数据库

1. 打开 **Navicat**（你电脑已装）
2. 左上角点 **连接** → 选 **MySQL**
3. 新建连接窗口填写：
   - 连接名：`本地MySQL`（随便起）
   - 主机：`localhost`（或 `127.0.0.1`）
   - 端口：`3306`
   - 用户名：`root`
   - 密码：**阶段1确认的密码**
4. 点 **测试连接** → 出现"连接成功"绿色提示 → 点 **确定**

**【成功验证】** 左侧导航栏出现"本地MySQL"，测试连接无红色报错。

**【新手避坑】**

- 报 `Access denied for user 'root'` → 密码不对，回阶段1重置密码再填
- 报 `Can't connect / 2003` → MySQL没启动，回 phpStudy 启动
- 想防止中文乱码：连接右键 → 编辑连接 → 高级 → 编码选 `UTF-8`（本脚本强制 utf8mb4，一般不会乱）

### 【阶段 3】执行建表脚本（核心动作）

**推荐方式（方式一）：**

1. 左侧**双击**刚建的"本地MySQL"连接
2. 点顶部 **文件 → 打开外部脚本**（或右键连接 → 运行SQL文件）
3. 选择文件：`F:\AI_full-stack_project\AppStore\sql\appstore_init.sql`
4. 点 **运行**（绿色三角 ▶）
5. 等待完成，底部消息面板最后应出现：```
数据库 appstore 初始化完成！共 11 张表 + 全部种子数据已导入。
```

> 
> 方式二（备用）：连接上右键 → **运行SQL文件** → 选该文件 → 开始。效果一样。

**【成功验证】**

- 底部消息面板**无红色报错**
- 左侧按 `F5` 刷新，能看到多出 `appstore` 数据库，展开后有 **11 张表**

**【新手避坑】**

- ❌ 只执行了部分SQL → 有些表没建出来。✅ 用"打开外部脚本"方式载入整个文件再运行（我推荐的就是整文件方式，不会漏）
- ❌ 第二次运行报"主键重复（Duplicate entry）"→ 脚本设计为一次性执行。✅ **不要重复执行**；真想重置，才取消脚本顶部第0段的 `-- DROP DATABASE` 注释后重跑
- ❌ 报 `Unknown database` → 没跑到建库段。✅ 确认是从文件开头执行

### 【阶段 4】验证数据库与数据

在 Navicat 里新建查询（`Ctrl+Q`），粘贴下面语句运行核对：

```
-- 1. 各表数据量统计（一次看全）
SELECT 'sys_user' AS '表名', COUNT(*) AS '记录数' FROM sys_user
UNION ALL SELECT 'sys_role', COUNT(*) FROM sys_role
UNION ALL SELECT 'sys_user_role', COUNT(*) FROM sys_user_role
UNION ALL SELECT 'app_category', COUNT(*) FROM app_category
UNION ALL SELECT 'app_info', COUNT(*) FROM app_info
UNION ALL SELECT 'app_version', COUNT(*) FROM app_version
UNION ALL SELECT 'app_comment', COUNT(*) FROM app_comment
UNION ALL SELECT 'app_favorite', COUNT(*) FROM app_favorite
UNION ALL SELECT 'app_download_record', COUNT(*) FROM app_download_record
UNION ALL SELECT 'app_audit_record', COUNT(*) FROM app_audit_record
UNION ALL SELECT 'sys_notice', COUNT(*) FROM sys_notice;

-- 2. 查看账号与密码加密情况（密码前缀应为 $2a$10$）
SELECT id, username, nickname, LEFT(password, 7) AS '密码前缀' FROM sys_user;
```

**期望核对结果：**

| 表 | 期望记录数 | 表 | 期望记录数 |
| --- | --- | --- | --- |
| sys_user | 7 | app_comment | 6 |
| sys_role | 3 | app_favorite | 4 |
| sys_user_role | 12 | app_download_record | 6 |
| app_category | 12 | app_audit_record | 9 |
| app_info | 10 | sys_notice | 2 |
| app_version | 10 |  |  |

**【成功验证】** 11张表全部存在、各表记录数完全吻合、密码前缀显示 `$2a$10$`（说明是加密的，不是明文）。
